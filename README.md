# js-image-modal

A small JavaScript practice project focused on building an image modal with keyboard interaction.

## Purpose
This project was built as a focused practice task to understand:
- DOM manipulation without libraries
- Event handling using JavaScript
- Keyboard interactions (Esc, Arrow keys)
- Managing state between user actions

## Features
- Click on an image to open it in a modal
- Close modal using the Escape key
- Navigate between images using keyboard arrows (Next / Previous)
- Clean separation between HTML, CSS, and JavaScript

## Why this project?
Instead of jumping into large applications, this project focuses on mastering one concept at a time.
The goal is to understand **why things work**, not just make them work.

## Technologies
- HTML
- CSS
- JavaScript (Vanilla JS)

## Status
This project is part of continuous practice and will be improved as new concepts are learned.
